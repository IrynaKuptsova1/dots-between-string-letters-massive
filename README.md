# Place dots between the letters in a word

Challange:
Input: word, output: all possible ways to place dots between its letters.

**Example:**
- Input: `abcd`
- Output:
1. abcd
2. abc.d
3. ab.cd
4. ab.c.d
5. a.bcd
6. a.bc.d
7. a.b.cd
8. a.b.c.d

To see the result, just run the file:  `node dots.ts` or `bun dots`

I decided to solve this task to practice working with variables, conditions, loops, strings and arrays, binary representation, and bitwise operations in JavaScript. I used my knowledge of algorithms, complexity, combinatorics, and iteration to solve this task.
